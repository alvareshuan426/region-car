# Region Car

Сайт детейлинг-студии Region Car: тонирование, бронирование полиуретаном, детейлинг.

Статическая страница без сборки — один `index.html` и папка `images/`.
Процесс тонирования и бронирования раскрывается при прокрутке.

## Публикация

Хостится на GitHub Pages из ветки `main`, папка `/` (корень).
Settings → Pages → Source: Deploy from a branch → main → /(root).

## Обновление

Правите `index.html`, затем:

    git add -A
    git commit -m "Что изменилось"
    git push

Через минуту изменения появятся на сайте.

## Локальный просмотр

    node server.mjs

Откроется на http://localhost:4321
